# 🦀 的网球手账

一个纯前端、可离线、可"添加到主屏幕"的网球个人工作台：**记账 + 训练记录 + 球场档案 + 自动报告**。
所有数据保存在你自己的设备上，不上传任何服务器。

---

## 一、本地预览

在项目目录执行（需要 Python，Windows/macOS 都自带或已装）：

```bash
python -m http.server 8123
```

然后浏览器打开 <http://127.0.0.1:8123>。
（**不要直接双击 index.html**：`file://` 下 Service Worker 和"添加到主屏幕"都不生效。）

---

## 二、部署到线上（iPhone 安装前必须做）

任选一个，都是免费且支持 https：

### 方案 A：GitHub Pages
1. 新建一个仓库，把本目录所有文件传上去。
2. 仓库 `Settings → Pages → Source` 选 `main` 分支 `/root`，保存。
3. 等 1 分钟，访问 `https://你的用户名.github.io/仓库名/`。

### 方案 B：Vercel / Netlify
1. 注册后选 "Deploy from folder / 拖拽上传"。
2. 把整个 `tennis-journal` 文件夹拖进去，自动生成 https 域名。

> 一定要用 **https**，否则 iOS 无法安装、离线缓存也不工作。

---

## 三、在 iPhone 上"添加到主屏幕"

1. 用 **Safari** 打开上面的 https 地址。
2. 点底部 **分享按钮**（方框 + 向上箭头）。
3. 选择 **「添加到主屏幕」**（若没有，点"编辑操作"加回来）。
4. 保持 **「以 Web App 打开」** 开启 → 点「添加」。

之后从桌面 🦀 图标进入，全屏无地址栏，和原生 App 一样。
App 内「设置 → 如何添加到主屏幕」也有同样的引导。

## 四、数据与备份

| 内容 | 存放位置 |
|---|---|
| 花费、训练记录、球场档案、设置 | `localStorage` |
| 照片、视频附件 | `IndexedDB`（Blob） |

- 两者都只在本机，刷新/关闭不丢；加到主屏后配额更大，也不会被 Safari 的 7 天清理波及。
- **换手机/防丢**：设置 → 导出 ZIP（含媒体）→ 新设备打开同一网址 → 导入备份。
- 只想备份文字：导出 JSON（不含照片视频）。

## 七、常见问题

**Q：改了名字，桌面图标名没变？**
A：iOS 的图标名在"添加到主屏幕"那一刻就固定了，改完名字需要删掉旧图标重新添加一次。

**Q：能多人/多设备同步吗？**
A：不能，纯本地。用导出/导入迁移。

**Q：视频太大存不下？**
A：iOS 给网页的存储约整机 60%（主屏 App），但单个 4K 视频可能几百 MB，建议传 1080p 或短片。
